# Delhi Water-Logging Hotspots Platform

A modern, data-driven GIS-enabled web platform for detecting, mapping, and predicting water-logging hotspots across Delhi.

## Features

- **Real-time Monitoring**: Interactive dashboard showing live water-logging conditions
- **Interactive Maps**: GIS-enabled maps with color-coded severity markers
- **Predictive Analytics**: AI-powered 24-hour forecasts and risk assessments
- **Citizen Reporting**: Easy-to-use form for reporting water-logging incidents
- **Analytics Dashboard**: Historical trends and ward-wise distribution data
- **Glassmorphism Design**: Modern UI with frosted glass effects and sky blue gradients
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices

## Design Features

- **Sky Blue Theme**: Beautiful gradient backgrounds with animated color shifts
- **Glassmorphism Effects**: Frosted glass cards with backdrop blur
- **Smooth Animations**: Elegant transitions and hover effects
- **Modern Typography**: Clean, readable Inter font family
- **Gradient Accents**: Sky blue gradients throughout the interface

## Deployment

### Deploy to Netlify

1. **Via Netlify CLI:**
   ```bash
   npm install -g netlify-cli
   netlify deploy --prod
   ```

2. **Via Netlify Dashboard:**
   - Connect your Git repository
   - Build settings are already configured in `netlify.toml`
   - Click "Deploy site"

3. **Via Drag & Drop:**
   - Go to [Netlify Drop](https://app.netlify.com/drop)
   - Drag the entire project folder
   - Your site will be live instantly

## Local Development

Simply open `index.html` in your browser. No build process required!
